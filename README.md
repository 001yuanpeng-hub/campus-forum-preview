# 重电校园站

面向**重庆电子科技职业大学**同学的非官方校园问答、经验沉淀与校园互助社区。

界面参考 LINUX DO / Discourse 的白底紧凑列表与左侧导航，主色采用重电官方视觉识别标准色 **「重电紫」（`#801C80`）**，后端使用 **零依赖 Node.js + 内置 SQLite**，目标是解决传统校园墙**消息容易过时、无法有效搜索、联系方式易泄露**等痛点。

> **正式在线地址（HTTPS）**：https://cquet.top/  
> **静态演示预览（GitHub Pages）**：https://001yuanpeng-hub.github.io/campus-forum-preview/  
> （前端会自动识别运行环境：部署在 Node.js 后端上时启用真实账号与数据库，在 GitHub Pages 上自动降级为本地演示模式。）

## 核心功能

- **真实账号体系 + 服务端轻校内验证**
  - 注册时由服务端随机下发重电校内常识题并在服务端校验答案（前端不暴露答案，防止校外广告号批量注册）。
  - 密码采用 `scrypt` 加盐哈希存储，会话使用 `HttpOnly + SameSite=Lax` Cookie，接口内置频率限制。
- **「校园互助」生命周期与联系方式保护**
  - 面向跑腿代取、二手闲置、拼车/搭子、失物招领等强时效场景，支持填写 **酬劳/价格、有效期（2 小时～长期）、独立联系方式**。
  - 状态自动流转：`进行中` → `已完成` / `已过期`，列表支持 **「仅看有效」** 一键过滤失效信息。
  - **服务端防爬取保护**：联系方式仅在「互助帖进行中 + 用户已登录」时由接口返回；未登录、结贴或过期后服务端绝不下发联系方式。
- **结构化版块、组合筛选与全文搜索**
  - 支持 **社区版块 × 校区（大学城 / 永川 / 两江）× 标签** 组合筛选，搜索（`/` 或 `Ctrl+K`）保留当前筛选并覆盖标题、正文与回复内容。
- **真实图片上传与客户端压缩**
  - 发帖支持选图或直接 `Ctrl+V` 粘贴截图（最多 4 张），前端自动压缩、后端校验文件头魔数后存入 `uploads/` 目录。
- **互动与个人体验**
  - **站内消息通知铃铛**：收到新回复、点赞或回答被采纳时自动出现未读提醒，点击直达对应楼层。
  - **点赞互动**：支持对帖子与回复点赞，「热门」排序综合浏览与点赞热度。
  - **发帖编辑 & 个人主页**：楼主可随时修改已发帖子（保留原附图或增删图片）；点击昵称可查看同学主页与历史发帖；账号弹窗内支持随时修改登录密码。
  - **手机端 PWA 支持**：配置 `manifest.json` 与重电紫图标，手机浏览器可「添加到主屏幕」像 App 一样打开。
- **社区管理与合规护栏**
  - 服务端内置违禁词拦截（自动拦截代课、代做作业、刷网课、替考等违规内容）。
  - 同学可一键举报违规帖子；站长（管理员）支持**置顶/取消置顶**、删帖、**处理举报**，以及直接在网页内**维护校内验证题库**。

## 本地启动（完整全栈版）

环境要求：**Node.js >= 22.5**（推荐 Node 24 LTS，使用内置 `node:sqlite`，**无需 `npm install`**）。

```bash
# 1. 可选：复制环境变量模板并修改管理员初始密码
cp .env.example .env

# 2. 直接启动服务（首次运行自动初始化 data/campus.db 与示例数据）
npm start
```

启动后访问 `http://127.0.0.1:3000/`。

- 默认初始管理员账号：`admin` / `cquet2026`（可在 `.env` 中通过 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 自定义，上线前请务必修改）。

```text
├── index.html         # GitHub Pages 入口跳转
└── README.md
```
