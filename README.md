# 重电校园站

面向**重庆电子科技职业大学**同学的非官方校园问答、经验沉淀与校园互助社区原型。

界面参考 LINUX DO / Discourse 的白底紧凑列表与左侧导航，主色采用重电官方视觉识别标准色 **「重电紫」（`#801C80`）**，目标是解决传统校园墙**消息容易过时、无法有效搜索、联系方式易泄露**等痛点。

> **在线预览（GitHub Pages）**：https://001yuanpeng-hub.github.io/campus-forum-preview/

---

## 核心功能（当前演示版）

- **结构化版块与多维筛选**
  - 支持按 **社区版块**（校园互助 / 课程与实训 / 实习与竞赛 / 校园生活 / 站务与指南）、**校区**（大学城 / 永川 / 两江）与 **标签** 组合筛选。
  - 顶部全文搜索（支持快捷键 `/` 或 `Ctrl+K`），搜索时保留当前校区/版块筛选，并覆盖标题、正文与回复内容。
- **「校园互助」生命周期管理**
  - 面向跑腿代取、二手闲置、拼车/搭子、失物招领等强时效场景，发帖支持填写 **酬劳/价格**、**有效期**（2 小时～长期）和 **独立联系方式**。
  - 自动状态流转：`进行中` → `已完成` / `已过期`，列表提供 **「仅看有效」** 一键隐藏已结束帖子。
- **轻校内验证与联系方式保护**
  - 通过重电校内常识题完成轻量验证后即可发帖、回复和查看互助联系方式（防校外广告）。
  - 互助帖结贴（标记为「已完成」）或过期后，联系方式**自动隐藏**，避免事后骚扰。
- **附图上传与客户端压缩**
  - 发帖支持选择图片或直接 `Ctrl+V` 粘贴截图（最多 4 张），前端自动压缩并支持点击查看大图。
- **桌面端与移动端自适应**
  - 宽屏容器上限 `1600px`，手机端自动精简统计列并在进入帖子详情时隐藏顶部筛选条。

## 本地运行

当前为纯原生 HTML / CSS / JavaScript 前端原型，**零依赖、无需构建**：

1. 直接用浏览器打开 [`dist/index.html`](./dist/index.html)；
2. 或在项目根目录启动本地静态服务：
   ```bash
   python -m http.server 8765 --directory dist
   ```
   然后访问 `http://localhost:8765/`。

> 注：演示版发帖、回复、结贴与验证状态保存在当前浏览器的 `localStorage` 中。
